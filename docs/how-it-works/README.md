# How Brickwright works

The visual guide is [`docs/how-brickwright-works.pdf`](../how-brickwright-works.pdf).
The repository README links it from **How it works**.

Rebuild it after editing `build_guide.py`:

```bash
python3 docs/how-it-works/build_guide.py
```

That writes `guide.html` beside this file and prints the PDF with headless Chrome.
